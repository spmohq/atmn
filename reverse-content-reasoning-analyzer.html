REVERSE CONTENT REASONING ANALYZER

Reverse Analysis Prompt

CONTEXT

Use the following reasoning hierarchy throughout the analysis.

- "Transformation" → The long-term change produced by consistently achieving the right Results.
- "Result" → The immediate outcome produced by taking the Action.
- "Action" → What should be done.
- "Rule" → The practical decision guideline that determines the Action.
- "Principle" → The universal truth that justifies the Rule.
- "Concept" → The underlying fundamental idea or reality from which the Principle arises.
- "Idea" → The author's expressed thought, viewpoint, or mental model built upon the Concept.

Important

- Every Idea or Concept is not necessarily true.
- A valid Idea must ultimately be supported by a valid Concept and true Principles.
- If the reasoning chain breaks at any point because of a false Principle or unsupported assumption, identify it.

---

BENGALI LOCALIZATION LAYER

Please write the output of the PROMPT below in the most spontaneous, natural-sounding modern conversational Bengali as spoken in Kolkata, West Bengal, India.

The writing should be easy for a 21-year-old to understand while maintaining high editorial quality, clarity, precision, and natural readability.

Strict Rules

- Reflect Kolkata conversational cadence through sentence rhythm and phrasing by using slightly formal, polite, and smoothly flowing sentence structures with balanced pacing. Avoid slang, regional grammar, overly literary wording, or awkward literal translations.
- Always use the formal "আপনি", never "তুমি".
- The tone should remain warm, conversational, approachable, confident, and quietly authoritative.
- Write as if speaking directly to one person in a natural face-to-face conversation.
- Do not translate literally. Rewrite naturally so the output feels as though it was originally written in Bengali.
- Preserve the original meaning, intent, emotional tone, and persuasive effect without adding, removing, or changing information.

INPUT

The uploaded document.

---

TASK

Starting from the highest known level, work backwards to reconstruct the complete reasoning chain.

Step 1 — Transformation

"Question:"

What long-term Transformation is the author ultimately trying to create?

---

Step 2 — Result

"Question:"

Why does this Transformation occur?

What Result must repeatedly happen to produce this Transformation?

---

Step 3 — Action

"Question:"

How is this Result achieved?

What specific Action produces this Result?

---

Step 4 — Rule

"Question:"

Why is this Action the correct one?

What Rule or decision guideline justifies taking this Action?

---

Step 5 — Principle

"Question:"

Why should this Rule be followed?

What universal Principle supports this Rule?

---

Step 6 — Concept

"Question:"

Where does this Principle come from?

What fundamental Concept or underlying reality gives rise to this Principle?

---

Step 7 — Idea

"Question:"

What Idea, viewpoint, or mental model has the author built upon this Concept?

---

ANALYSIS RULES

1. Base every conclusion primarily on the uploaded document.

2. Prefer explicit information over inferred information.

3. Infer only when the document strongly supports the conclusion.

4. Never invent missing information.

5. If a level cannot be confidently identified, write:

   "Not explicitly stated"

   and briefly explain why.

6. Explain how each level logically leads to the previous one.

7. If the reasoning chain contains logical gaps, unsupported assumptions, or contradictions, identify them.

8. If a Principle appears false or unsupported, explain how that affects the rest of the reasoning chain.

---

OUTPUT

Return the analysis as the following Markdown table.

| Transformation | Why did this Transformation occur? | Result | | |
| Result | How was this Result achieved? | Action | | |
| Action | Why was this Action taken? | Rule | | |
| Rule | Why this Rule? | Principle | | |
| Principle | Where does this Principle come from? | Concept | | |
| Concept | What Idea is built upon this Concept? | Idea | | |

Logical Assessment

After completing the table, evaluate the reasoning chain.

Include:

- Whether the chain is complete.
- Any missing logical links.
- Unsupported assumptions.
- Weak or false Principles.
- Whether the final Idea is logically consistent with the underlying Concept and Principles.
- Overall reasoning quality (Excellent / Strong / Moderate / Weak) with a brief justification.
